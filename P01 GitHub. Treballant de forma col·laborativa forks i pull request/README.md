## 🌟 Introducció i Context
A **EverPia**, el treball en equip es coordina de manera professional. És impensable treballar en una sola branca `main` o enviar fitxers de configuració per correu. Per aquest motiu, en aquesta activitat es simula el procés d'**Onboarding** (incorporació) de nous consultors mitjançant un flux de treball estricte de Git i GitHub.

L'objectiu principal és dominar les eines clau de col·laboració del sector tecnològic: **Forks**, **Branques de funcionalitat** i **Pull Requests (PR)** amb revisió de codi.

---

---

## 🔄 Flux de Treball a EverPia
El camí que segueix qualsevol línia de codi o configuració a la nostra consultora és el següent:

1.  🍴 **Fork:** Cada membre fa una còpia del repositori base al seu compte personal de GitHub.
2.  👥 **Clone & Branch:** Es clona en local i es treballa sempre en una branca específica per a la tasca.
3.  🚀 **Push & Pull Request:** Es pugen els canvis al GitHub personal i es sol·licita la fusió (*Pull Request*) cap al repositori de l'equip.
4.  👀 **Code Review:** El Team Leader revisa que tot estigui correcte abans d'acceptar els canvis al projecte final.
