# T08: Auditoria de Qualitat i Estandardització de Servidors (Tasca Individual)

## 📝 Breu Descripció

Aquesta unitat se centra a consolidar les bases dels sistemes operatius abans de desplegar serveis avançats (com NFS, CUPS o LDAP)[cite: 1]. Per garantir la fiabilitat, seguretat i robustesa de qualsevol infraestructura, és imprescindible aplicar un **Protocol de Desplegament Estàndard (SOP - Standard Operating Procedure)**[cite: 1]. 

L'objectiu és aprendre a auditar, estandarditzar i configurar des de zero una màquina virtual base de manera excel·lent, minimitzant riscos de seguretat i futures incidències[cite: 1].

---

## 🚀 La Vostra Missió

Com a consultors, abans de tocar l'entorn d'un client real, cal dominar el protocol de configuració bàsica de la infraestructura[cite: 1]. Les tasques clau d'aquesta missió consisteixen en:

1. **Desplegar** una nova màquina virtual (Ubuntu Server) des de zero[cite: 1].
2. **Aplicar** el protocol de configuració bàsica (xarxa, permisos, actualitzacions de paquets)[cite: 1].
3. **Auditar** de forma interna el servidor base per assegurar els fonaments del sistema[cite: 1].

---

## 🛠️ Fases del Mòdul

### 🏋️ 1. Fase d'Entrenament
* **Acció:** Descarregar el document **Projecte4-TascaSOP** disponible a la plataforma[cite: 1].
* **Pràctica:** Executar les tasques indicades a partir de la imatge OVA proporcionada[cite: 1].
* **Lliurament:** *No cal lliurar cap activitat*[cite: 1]. L'objectiu és practicar i entendre perfectament el funcionament de cada tasca per preparar-se[cite: 1].

### 🎓 2. Certificació (SOP-Specialist)
* **Avaluació:** Un cop finalitzat l'entrenament, s'haurà de superar un **examen pràctic exigent** per validar els coneixements[cite: 1].
* **Condicions de la prova:** Per realitzar l'examen, únicament es permetrà l'accés amb **un full manuscrit** que contingui les anotacions i comandes que creguis necessàries[cite: 1].
