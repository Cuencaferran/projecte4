# T12: Fonaments del Disseny Web Comercial — Landing Page + Procés de Checkout

## 📝 Breu Descripció

Aquesta unitat consta d'una **classe magistral** enfocada a analitzar i estructurar els dos pilars essencials d'un comerç electrònic: la **Landing Page** i el **Procés de Checkout**. 

Abans de començar a dissenyar la maqueta completa de l'e-commerce per al client d'*EverPia*, és fonamental comprendre la psicologia i el recorregut (*user journey*) de l'usuari des del moment en què aterra a la pàgina web amb una intenció d'interès, fins que completa l'acció final de compra de manera satisfactòria.

---

## 🎯 Continguts i Aprenentatges Clau

Durant la sessió es treballen en profunditat els següents blocs de disseny comercial:

* **Estructura Web Comercial:** Com es distribueixen els elements visuals per guiar l'usuari cap a la conversió.
* **La Landing Page (Pàgina d'Aterratge):** Tècniques de maquetació orientades a retenir l'atenció i transmetre propostes de valor clares. Anàlisi del model de *landing pages* de format llarg o "quilomètriques".
* **El Procés de Checkout (Pas per Caixa):** Bones pràctiques en el disseny de formularis de pagament per reduir la taxa d'abandonament de carretons, optimitzant la usabilitat i la claredat en les pantalles finals.
